# Examples

- `lm-studio-mcp.json`: ready-to-paste LM Studio MCP config for the hosted server.
- `remote-mcp-entry.json`: generic remote SSE MCP server entry with API key placeholder.
- `prompt-playbook.md`: practical prompt flows for onboarding, portfolio creation, analysis, optimization (Sharpe, min-vol, HRP, HERC, ERC), benchmark comparison, and settings discovery. All prompts work with the guest key.
- `tool-call-examples.md`: argument payload examples for key MCP tools — create, analyze, optimize (Sharpe, vol, HRP, ERC), compare benchmark, and feedback. All examples work with the guest key.
